Custom theme files live in this folder.

Each theme is a JSON file like this:

{
  "name": "My Theme",
  "colors": {
    "bg": "#1e1e1e",
    "panel_bg": "#252526",
    "text": "#e6e6e6",
    "accent": "#7aa2f7",
    "header_bg": "#2d2d30",
    "header_fg": "#ffffff",
    "status": "#ff6b6b",
    "theme_selector_bg": "#ffffff",
    "theme_selector_text": "#000000",
    "profile_selector_bg": "#ffffff",
    "profile_selector_text": "#000000",
    "nametape_bg": "#ffffff",
    "nametape_text": "#000000",
    "search_bg": "#ffffff",
    "search_text": "#000000"
  }
}

How sharing works:
- Export a theme from the app, or copy one of the JSON files in this folder.
- Another person can drop the file into their own Themes folder or use the Import button.
- The app will show it in the Theme selector automatically.

Color keys:
- bg: main app background
- panel_bg: preview panel and input field background
- text: normal text color
- accent: section heading color
- header_bg: top bar background
- header_fg: top bar text color
- status: status and error text color
- theme_selector_bg: top theme dropdown background
- theme_selector_text: top theme dropdown text
- profile_selector_bg: profile dropdown background
- profile_selector_text: profile dropdown text
- nametape_bg: nametape entry background
- nametape_text: nametape entry text
- search_bg: search entry background
- search_text: search entry text
